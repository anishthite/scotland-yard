# Data attribution

The station coordinates and transport connections in `src/data/*.txt` were adapted from the public
[`AlexElvers/scotland-yard-data`](https://github.com/AlexElvers/scotland-yard-data) dataset. The data
was independently validated at build/test time for station count, valid endpoints, duplicate routes,
and undirected connectivity.

Starting-position pools are factual game data cross-checked against the public implementation at
[`tim-koehler/ScotlandYard`](https://github.com/tim-koehler/ScotlandYard).

All application layout, styling, icons, effects, copy, and map rendering in this repository are original.
